Project Progress Dashboard — วิชาโครงการ ปวส. 2

⚙️ อัปเดตความก้าวหน้า

บันทึก = จำค่าที่ปรับไว้ในเครื่องนี้ (รีเฟรชแล้วไม่หาย) และเห็นผลที่แท็บ "แดชบอร์ด" ทันที แต่คนอื่นยังไม่เห็น
ถ้าต้องการให้ทุกคนเห็น: กดบันทึก → กดดาวน์โหลดไฟล์ → นำไฟล์ progress.json ไปอัปโหลดทับไฟล์เดิมใน GitHub (Add file → Upload files → Commit changes) รอประมาณ 1 นาทีแล้วรีเฟรชหน้าเว็บ
🔗 เชื่อม GitHub (ให้ปุ่มบันทึกส่งขึ้นเว็บเอง)
วิธีสร้าง token: GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token → เลือก Only select repositories เฉพาะ project-dashbord → ตั้ง Contents เป็น Read and write
token จะถูกเก็บในเบราว์เซอร์ของเครื่องนี้เท่านั้น ห้ามส่งให้ใครหรือใส่ในโค้ด
✅ เชื่อมต่อแล้ว กดบันทึกแล้วขึ้นเว็บทันที
